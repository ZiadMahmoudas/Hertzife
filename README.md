# ORBS Static Website Design

Static front-end design only (HTML/CSS/JS) for the ORBS apple store concept.

## Pages included
- Home: `index.html`
- Products: `products.html`
- Product details: `product-details.html`
- Blogs: `blogs.html`
- Blog article: `blog-details.html`
- Contact: `contact.html`
- Cart: `cart.html`
- Login: `login.html`
- Sign up: `signup.html`

## Tech
- HTML5
- CSS3
- Vanilla JavaScript
- Font Awesome CDN
- Local image assets

## Notes
This is a visual/static design. Cart, login, checkout, and forms are demo interactions only and are not connected to a backend.
